Portfolio Website

A modern and responsive personal portfolio website built to showcase projects, skills, experience, and contact information. This project highlights clean UI/UX design, responsive layouts, and interactive frontend development practices. Inspired by modern developer portfolios and built for performance across devices.

🚀 Features
Responsive design for desktop, tablet, and mobile
Smooth scrolling and interactive UI
Project showcase section
Skills and technologies section
About me and contact sections
Clean and modern portfolio layout
Fast-loading frontend implementation
Easy customization for personal branding

🛠️ Tech Stack
HTML5
CSS3
JavaScript
Responsive Web Design
